# Contributing

## Sign the manifesto
1. Fork this repository.
2. Add one line at the end of [SIGNATORIES.md](SIGNATORIES.md).
3. Open a pull request titled `Sign: <your name>`.

## Propose a change to the guide
Open an issue first. Changes to the guide should come from practice: describe what you tried, on what kind of project, and what happened. Proposals without evidence are labeled `proposal` until someone validates them.

## Translations
Translations are welcome under the same license (CC BY-SA 4.0). Add `guide.<lang>.html` and link it from the manifesto.
